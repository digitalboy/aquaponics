# 竞道 JD-QC-X 五要素自动气象站产品手册

## 一、产品简介

小型自动气象站是一款高度集成、低功耗、可快速安装、便于野外监测使用的高精度气象观测设备。

该设备由**气象传感器、太阳能供电系统与立杆支架**组成。免调试、可快速布置，广泛应用于气象、农业、林业、环保、海洋、机场、港口、科学考察、智慧温室与校园教育等领域。

---

## 二、产品特点

* **低功耗采集器**：静态工作功耗小于 $1\,\text{mA}$。
* **标准工业接口**：标配 **RS485 Modbus-RTU** 输出，原生支持接入 PLC、工控机与边缘网关。
* **模块化扩展**：支持 Modbus-485 传感器进一步级联扩展。
* **智能电源管理**：配备 $150\,\text{W}$ MPPT 太阳能自动最大功率点跟踪充电管理，充放电效率提升 $20\%$。
* **耐候结构支架**：采用 $3\,\text{m}$ 碳钢支架，两节法兰盘对接紧固。
* **高防护等级**：不锈钢材质防护箱，耐腐蚀、抗氧化，整机防水防尘等级达 **IP66**。

| 参数项 | 技术规格 |
| :--- | :--- |
| **传感器接口** | GX-12-4P 航空插头 |

## 四、上位机软件功能

1. **多协议兼容**：支持串口直接接收、处理并展示 Modbus-RTU / JSON 格式数据流。
2. **自定义采集与存储周期**：支持按秒级/分钟级自定义轮询采样时间与历史数据库归档周期。
3. **参数灵活定义**：支持在界面中自主增加、删除、修改监测参数的协议定义、名称、量程与 UI 状态图标。
4. **数据分析与后处理**：提供趋势图表绘制、历史报表导出、极值统计与数据后处理分析能力。
5. **脚本扩展**：支持外置运行 JavaScript 脚本进行复杂联动逻辑处理与第三方接口推送。
