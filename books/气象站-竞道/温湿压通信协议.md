# 竞道 温湿度大气压一体式传感器通信协议规范 (Temp, Humidity & Barometric Pressure Sensor)

## 一、技术指标与电气参数

| 参数项 | 技术规格 |
| :--- | :--- |
| **供电电压** | DC $12\,\text{V}$ |
| **工作电流** | $2\,\text{mA} @ 12\,\text{V DC}$ |
| **工作环境** | 温度: $-40 \sim +80^\circ\text{C}$，湿度: $\le 100\%RH$ 无凝露 |
| **通信接口** | RS485 (标准 Modbus-RTU 协议) |

| **外壳材料** | 耐候高分子工程塑料（防雨百叶罩设计） |

## 二、传感器串口通信配置 (Serial Config)

| 通信参数 | 默认设置 | 备注说明 |
| :--- | :--- | :--- |
| **设备默认地址** | `0x66` (十进制：`102`) | 地址可设范围：`0x01` $\sim$ `0xFF` (1~255) |
| **默认波特率** | `9600 bps` | 可配置：4800 / 9600 / 56000 / 115200 bps |
| **数据位 (Data Bits)** | 8 位 | 标准数据位 |
| **停止位 (Stop Bits)** | 1 位 | 标准停止位 |
| **校验位 (Parity)** | 无校验 (None) | 8-N-1 格式 |
| **CRC 校验顺序** | CRC-16 (Modbus) | **低字节在前，高字节在后** |

## 三、Modbus-RTU 通信示例

### 3.1 `03` 功能码：读取温度值

* **上位机发送请求帧**：
  ```hex
  66 03 00 00 00 01 8C 1D
  ```
  * `66`：设备地址（十进制 102）
  * `03`：读保持寄存器功能码
  * `00 00`：温度寄存器起始地址
  * `00 01`：读取 1 个寄存器
  * `8C 1D`：CRC-16 校验码

* **传感器应答响应帧**：
  ```hex
  66 03 02 0A 02 0A ED
  ```
  * `66`：设备地址
  * `03`：功能码
  * `02`：返回数据字节数（2 字节）
  * `0A 02`：原始温度数据 ($0\text{x}0\text{A}02 = 2562$)
  * `0A ED`：CRC-16 校验码

* **数值解析**：
  $$\text{真实温度} = \frac{0\text{x}0\text{A} \times 256 + 0\text{x}02}{100} = \frac{2562}{100} = 25.62^\circ\text{C}$$

---

### 3.2 `06` 功能码：修改波特率与设备地址

#### 1. 修改传感器波特率为 115200 bps
* **发送**：`66 06 00 05 00 04 90 1F`
* **接收**：`66 06 00 05 00 04 90 1F`
* > [!IMPORTANT]
  > 发送修改波特率指令成功后，必须将传感器**断电重启**，新的通信参数才能生效。

## 四、Modbus 寄存器地址映射表 (Register Map)

| 寄存器地址 (Hex) | 寄存器地址 (Dec) | 参数名称 | 操作权限 | 数据格式 | 单位 / 换算规则 | 备注说明 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`0x0000`** | 0 | **环境温度 (Temperature)** | 只读 (`03`) | `Int16` (有符号) | 实际温度 ($^\circ\text{C}$) = 读数 $/ 100$ | 支持零下负温 |
| **`0x0001`** | 1 | **相对湿度 (Humidity)** | 只读 (`03`) | `Uint16` | 实际湿度 ($\%RH$) = 读数 $/ 100$ | 范围 $0 \sim 100.00\%$ |
| **`0x0002`** | 2 | **大气压力 (Pressure - hPa)** | 只读 (`03`) | `Uint16` | 实际气压 ($\text{hPa}$) = 读数 $/ 100$ | 百帕 / 毫巴 |
| **`0x0004`** | 4 | **设备地址 (Device Address)** | 读写 (`03`/`06`) | `Uint8` | - | 范围：`0x01` $\sim$ `0xFF`，默认 `0x66` (102) |

## 五、使用与安装注意事项

> [!NOTE]
> 1. **接线极性与防反接**：严格遵循接线定义，避免 DC $12\,\text{V}$ 极性反接或信号线接错导致内部芯片损坏。
> 2. **防浸泡与防溅水**：传感器百叶罩具备防自然雨淋设计，但**严禁浸入水中或承受高压水枪喷射**。
> 3. **避免热源直射**：安装位置应远离空调出风口、温室补光灯发热源或排气管，安装于通风良好的背阴面或气象横臂上。
> 4. **空间微气候扩散影响**：在非标准受限空间中，局部气流不均匀会造成温度扩散滞后，此属正常物理现象，非传感器测量失真。
> 5. **恶劣环境限制**：禁止在强酸、强碱、高浓度硫化氢或极度腐蚀性气体环境中使用。
