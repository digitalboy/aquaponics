## 二、 专业术语词典（Glossary）

| 术语词条 (English Term) | 规范中文译名 | 专业科学定义与工程注解 |
| :--- | :--- | :--- |
| **Acid** | 酸 | 在水中能解离出水合氢离子（$\text{H}^+$）、使石蕊试纸变红且能中和碱的化学物质。鱼菜中共生常用食品级磷酸调降过高 pH。 |
| **Ammonia-oxidizing bacteria (AOB)** | 氨氧化细菌 | 专性化能自养微生物（如亚硝化单胞菌 *Nitrosomonas* spp.），负责硝化第一步：在好氧条件下将游离非离子氨（$\text{NH}_3$）氧化为有毒亚硝酸盐（$\text{NO}_2^-$）。 |
| **Base** | 碱 | 能够中和酸性物质并使水溶液 pH 升高的化学物质。鱼菜系统中推荐使用氢氧化钙或碳酸氢钾作为补充植物营养的优质弱碱。 |
| **Biofilter** | 生物滤器 | 系统中的生化反应室，填充具有极大比表面积（SSA）的惰性载体，专供数以亿计的自养硝化菌和异养菌定殖形成生物被膜以脱毒净水。 |
| **Biofilm** | 生物被膜 / 菌膜 | 微生物在固体载体表面分泌胞外多聚物基质（EPS）形成的微生态膜层结构。 |
| **Biomass ratio** | 生物量比率 | 系统中养殖鱼类的总活体质量与水培植物总生物量或有效种植面积之间的化学计量平衡比例。 |
| **Buffer** | 缓冲剂 / 缓冲溶液 | 具有抵抗外源强酸或强碱冲击、保持溶液 pH 相对稳定的化学物质对（如水中的碳酸氢根/碳酸根缓冲对）。 |
| **CHIFT-PIST** | 鱼池恒定水位-泵置集水箱 | 经典水力学安全构型英文缩写（*Constant Height In Fish Tank – Pump In Sump Tank*）。鱼池采用高位重力溢流，水泵仅置于低位集水箱，物理杜绝断管漏水抽干鱼池。 |
| **Denitrification** | 反硝化脱氮作用 | 在完全缺氧或厌氧（$\text{DO} < 1\text{ mg/L}$）条件下，异养反硝化细菌夺取硝酸根中的氧，将 $\text{NO}_3^-$ 还原为一氧化二氮或无害氮气（$\text{N}_2$）逸散的过程。 |
| **Digestible energy (DE)** | 消化能 | 饲料摄入总能扣除排泄粪便所含能量后，可被鱼类消化道实际吸收利用的有效能量。 |
| **Dissolved oxygen (DO)** | 溶解氧 | 呈分子态物理溶解于水体中的氧气量（单位：$\text{mg/L}$）。鱼菜系统维持生命运行的首要控制红线（通常要求 $> 5.0\text{ mg/L}$）。 |
| **Electrical conductivity (EC)** | 电导率 | 水溶液传导电流能力的物理量，直接反映水体中全部溶解态无机盐矿质离子的总摩尔浓度（单位：$\mu\text{S/cm}$ 或 $\text{mS/cm}$）。 |
| **Feed conversion ratio (FCR)** | 饲料系数 / 饲料转化比 | 消耗配合饲料总干重与养殖鱼体净增活重的比值：$\text{FCR} = \Delta \text{Feed} / \Delta \text{Biomass}$。数值越低表明饵料转化效率越高。 |
| **Feed rate ratio** | 投饵量比率 | 维系鱼菜动态平衡的核心设计比率：每日投喂给鱼类的全价饲料克数与植物有效种植床表面积之比（绿叶菜 $40\sim 50\text{ g/m}^2/\text{d}$，果菜 $50\sim 80\text{ g/m}^2/\text{d}$）。 |
| **Flood and drain (Ebb and flow)** | 潮汐间歇灌溉法 | 介质床栽培中利用自动钟罩虹吸阀实现的水位周而复始涨落退潮循环机制。退潮负压强行吸入大气氧气，滋养根系与菌膜。 |
| **Footprint (Ecological footprint)** | 生态足迹 | 维持特定人类活动或生产系统所需消耗的耕地、水资源与同化吸收废弃物所需的生物生产性土地总面积度量。 |
| **Hardness (Water hardness)** | 水质硬度 | 水中溶解的多价金属阳离子（主要为 $\text{Ca}^{2+}$ 与 $\text{Mg}^{2+}$）的总摩尔浓度当量。换算关系：  <br>$$50\text{ mg/L CaCO}_3 = 1\text{ meq/L} = 2.805\text{ }^\circ\text{dH} = 28\text{ mg/L CaO}$$ |
| **Heterotrophic bacteria** | 异养细菌 | 必须利用预先存在的现成有机化合物作为碳源与能源的微生物群落，在系统中主导固态鱼粪与残饵的快速水解与生物矿化。 |
| **Hydraulic retention time (HRT)** | 水力停留时间 | 水体或溶解质在沉淀槽、生化池或深水水培槽中平均驻留反应的时间（$\text{HRT} = V / Q$）。 |
| **New tank syndrome** | 新缸综合征 | 新建水产或鱼菜系统由于生物滤膜尚未成熟，投入鱼类后导致游离剧毒非离子氨和亚硝酸盐迅速飙升并引发鱼群批量暴毙的病理综合征。 |
| **Nitrification** | 硝化反应 | 由自养化能硝化菌群（AOB 与 NOB）在充足氧气驱动下，将有毒非离子氨依次氧化为亚硝酸盐、最终氧化为无害硝酸盐的两步好氧生化反应。 |
| **Nitrite-oxidizing bacteria (NOB)** | 亚硝酸盐氧化细菌 | 专性自养化能菌（如 *Nitrobacter* 与 *Nitrospira* spp.），负责硝化第二步：将有毒亚硝酸盐（$\text{NO}_2^-$）进一步氧化为植物肥料硝酸盐（$\text{NO}_3^-$）。 |
| **Nutrient lockout** | 养分吸收锁死（pH依赖性吸附沉淀）| 当水体 pH 偏离最佳适宜区间（如 $\text{pH} > 7.5$）时，即使水中存在充足铁、磷、锰等元素，这些离子也会相互化合沉淀为不溶性螯合物，导致植物根系完全无法吸收利用的病态现象。 |
| **Photoperiodism** | 光周期现象 | 动植物对昼夜相对长度变化的生理反应（如长日照诱导生菜抽薹开花，短日照诱发鱼类产卵迁徙）。 |
| **Soil tiredness (Sick soil)** | 土壤连作障碍 / 土地疲劳症 | 同一地块常年连续单作同种作物导致的土壤退化现象，由微量营养耗竭、土壤板结、专性土传病原菌（线虫、枯萎菌）富集与根系自毒分泌物累积共同造成。 |
| **Specific surface area (SSA)** | 比表面积 | 滤料或多孔基质单位体积所具有的总微观有效表面积（单位：$\text{m}^2/\text{m}^3$）。决定生物滤器承载自养硝化菌群总容量的核心几何指标。 |
| **Stocking density** | 放养存塘密度 | 单位水体容积所蓄养的鱼类总重量（单位：$\text{kg/m}^3$ 或 $\text{kg/1000升水}$）。小型安全鱼菜系统推荐维持在 $10\sim 20\text{ kg/m}^3$。 |
| **System cycling** | 开缸养水循环 | 新建系统投放主要经济水生动物前，人工持续投加外源氨源，诱导并构建起完整成熟的 AOB 与 NOB 菌膜种群的 3~5 周前期生化培育周期。 |
| **Total ammonia nitrogen (TAN)** | 总氨氮 | 水体中存在的剧毒游离非离子氨（$\text{NH}_3$）与低毒铵离子（$\text{NH}_4^+$）的氮总和浓度。两者平衡强烈受水温与 pH 驱动。 |
| **Turnover rate** | 水体循环置换速率 | 系统单位时间内循环置换的水量与总水体容积之比（$Q/V$，单位：$\text{次/小时}$）。小型鱼池通常要求每小时循环置换 1~2 次。 |
| **Wicking bed** | 毛细自吸芯吸种植床 | 利用封闭底层储水库的微细毛细管自吸原理自下而上浸润上层沙壤土的创新种植床，突破传统水培限制，能够高产优质栽培土豆、胡萝卜等块根块茎农作物。 |
