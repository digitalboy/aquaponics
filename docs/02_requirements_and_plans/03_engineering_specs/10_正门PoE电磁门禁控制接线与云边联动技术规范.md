## 1. 系统架构与 25 米 PoE 供电设计

### 1.1 为什么采用 48V PoE 而非直接拉 25 米 12V 直流电

中央控制柜 `AP-CTRL` 到正门口线缆长度约 **25 米**（单程），若直接从控制柜输出 12V 直流电：
- 按 280KG 磁力锁工作电流 $I \approx 0.5\,\text{A}$ 计算，普通 `0.5mm²` 导线来回 $50\,\text{m}$ 回路电阻约 $1.8\,\Omega$，线损压降近 $1\,\text{V}$；若瞬间叠加控制器功耗（$1\,\text{A}$），末端电压跌破 $10.5\,\text{V}$ 会导致磁力锁吸力明显下降或继电器掉电重启。
- 采用 **IEEE 802.3at 标准 PoE（48V 直流）** 经 `Cat5e STP` 网线送至门口，电流仅约 $0.15\sim 0.25\,\text{A}$，25 米压降可忽略不计；到达正门内侧防水接线盒后，再由 **PoE 分离器（12V / 2A）** 就近稳压输出 `12.0V` 给电磁锁与网口继电器供电，并同时享受到控制柜 UPS 的集中断电保护。

### 1.2 网络与控制拓扑

```text
[中央控制柜 AP-CTRL]
  ├─ 倍控 N100 工控机 (video-agent, 192.168.0.50 / 192.168.1.50)
  └─ 深桑科 GPS424 V3 PoE+ 交换机 (接入柜内 UPS)
        │
        └─ Port 09 ══(25米 Cat5e STP 屏蔽网线，48V PoE + 数据)══╗
                                                               ║
[正门内侧干燥位 · IP65 防水接线盒]                              ▼
  ├─ 802.3at PoE 分离器 (输入 RJ45 48V → 输出网口数据 + DC 12V/2A)
  │     ├─ 网口数据 ──► 2路网口继电器 (静态 IP: 192.168.1.120)
  │     └─ DC 12V ────► 电源母线 (同时供继电器、电磁锁与声光报警器，峰值总功耗 ~12.8W < 24W)
  ├─ 物理出门按钮 (NC 常闭串联，不经过继电器直接断电)
  ├─ 280KG 五线电磁锁 (DO1 COM-NC + 1N4007 续流二极管 + 门磁接入 DI1)
  └─ DC 12V 声光报警器 (DO2 COM-NO 常开控制，额定电流 ≤ 500mA)
```

## 2. 电气安全与防反锁硬规范（施工强制项）

1. **Fail-Safe（断电开锁）逻辑**：
   - 电磁锁正极必须经过 **网口继电器的 `COM → NC（常闭）` 触点**；
   - 常态下继电器不吸合，`COM-NC` 导通，电磁锁得电吸合上锁；
   - 需要开门时，N100 下发“脉冲吸合 5 秒”指令，继电器 `COM-NC` 断开 5 秒，门锁失电打开；5 秒后自动复位重新上锁。
2. **物理出门按钮强制串联（最高优先级）**：
   - 门内侧 1.2m 高度安装的物理出门按钮，其 **NC（常闭）触点必须直接串联在 `12V+` 进入电磁锁之前**；
   - 无论继电器死机、N100 关机或交换机断网，人员在门内按下按钮即物理切断 12V 电源直接出门。
3. **续流二极管浪涌保护（必须加装）**：
   - 电磁锁内部为大电感线圈，断电瞬间会产生高压反电动势；
   - 接线时必须在电磁锁接线端子 `+12V` 与 `GND` 之间**反向并联 1 颗 `1N4007` 二极管**（白环/阴极接 `+12V`，阳极接 `GND`），防止电弧烧蚀继电器触点或损坏 PoE 分离器。
4. **门磁状态反馈接线（五线制）**：
   - 将电磁锁的门磁信号线（`COM` 与 `NO`/`NC`，按实际吸合闭合状态选用）接入网口继电器的 `DI1` 开关量输入端；
   - 业务层据此判断“门已锁紧 / 门未关严（虚掩）”，可结合夜间布防在门长时间未锁紧时向飞书群发提醒。
5. **严禁共线干扰**：
   - 电磁锁单独占用交换机 `Port 09`，**不得与海康枪机共用同一路 PoE 分离器**，防止锁体通断引起的电源波动导致摄像头掉线。

## 3. 人脸开锁安全策略（2D 人脸 vs 双目活体）

| 阶段 | 解锁触发方式 | 安全策略说明 |
| :--- | :--- | :--- |
| **Phase 1（当前 2D 摄像头 + PoE 电磁锁）** | **管理后台 / 飞书卡片手动“远程开门 5 秒”** + 门内物理出门按钮 + 机械钥匙 | **禁止直接将高位 2D 人脸识别绑定为无人值守自动开锁**。原因：现有摄像头无红外活体检测，存在手机照片/平板视频欺骗开锁风险；人脸识别用于快速识别熟人身份并推送飞书，由管理员确认或现场人员刷卡/远程一键开门。 |
| **Phase 2（加装 13.8 双目活体一体机）** | **门口双目红外活体刷脸（0.3s 秒开）** + IC 卡 + 密码 + 远程开门 | 双目活体一体机直接并入继电器开锁回路，自身脱机校验活体与身份，既防照片欺骗又不受工控机断网影响。 |

## 4. 软件云边联动接口规范（后续编码对齐基准）

当硬件安装调试就绪后，在现有 `video-gateway` + `video-agent` 架构上仅需增量扩展以下接口即可完成联动：

1. **云端指令下发（`video-gateway`）**：
   - 在 `agent_commands` 的 `action` 中新增 `'unlock_door'`（`payload_json: {"door_id": "GATE-OUT-01", "duration_sec": 5}`，超时时间 `expires_at` 严格设为 **15 秒内**，防止断网重连后延迟半天突然自动开门！）；
   - 仅限已通过 **飞书 OAuth 登录** 的授权管理员（`ADMIN_FEISHU_OPEN_IDS` 白名单）在管理后台触发，并强制写入 `video_events` 审计日志（操作人 `open_id`、姓名、时间 ISO 8601 UTC）。
2. **边缘脉冲执行（`video-agent`）**：
   - N100 心跳（活跃态 3 秒轮询，或按需缩短）收到 `unlock_door` 后，先校验 `expires_at` 未过期，再向门口网口继电器（如 `http://192.168.1.120/...`）发送 5 秒点动指令；
   - 执行完成后回传 `ack` 及 `DI1` 门磁状态。
3. **开门次数统计、超时未关报警与声光现场联动（基于五线锁 `DI1` + 报警器 `DO2`）**：
   - **状态边沿采集**：N100 每 `1s` 轮询继电器 `DI1` 开关量；检测到 **`闭锁 → 打开`** 边沿即记录一次开门事件（精确统计每日开门次数、打开时刻、关门时刻与单次敞门时长，可覆盖远程开门、物理出门按钮及机械钥匙开门）；
   - **超时未关告警（默认 `30s`）**：当门连续处于“未吸合/打开”状态超过 **`30` 秒**时，N100 立即抓拍现场图上传 R2 并触发云端 **飞书带图红色告警卡片 + 告警邮件**，同时触发 `DO2` 声光报警器间歇提示（门重新吸合后立刻静音并推送恢复通知）；
   - **夜间陌生人声光震慑**：日落后至日出前布防时段，N100 检测到人且**未匹配到在职员工人脸**时，触发 `DO2` 声光报警器爆闪鸣笛 **`8` 秒**（限时震慑避免半夜持续扰民），并同步推送飞书红框大图告警卡片；识别为已登记员工（如张扬）时不触发声光报警器。
   - **管理后台消音兜底**：保留「手动关闭声光报警 (`DO2`)」指令，方便特殊作业时远程一键静音。
