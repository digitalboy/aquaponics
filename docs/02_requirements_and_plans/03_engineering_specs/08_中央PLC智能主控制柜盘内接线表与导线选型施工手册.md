### 1.3 必备配套辅料小配件（千万别漏）

1. **柜门防静电接地软铜编织带**：
   - **技术规格**：镀锡铜接地编织带，截面 $4.0\sim 6.0\,\text{mm}^2$，长度 $25\sim 30\,\text{cm}$，两端已冷压带 M5/M6 圆形铜鼻子；
   - **数量**：**1 根**（约 ¥3~5 元）；
   - **安装要求**：连接柜门下方的接地螺栓跨接到柜体底板 PE 螺栓上，不要自己用线手工压，成品的抗疲劳寿命极长，频繁开关门永不断裂。
2. **号码管（线号管）**：
   - **机打热缩管方案**：如果手头有热缩管打印机，请准备内径 **$\Phi 2.5\,\text{mm}$**（用于 0.5~0.75mm² 导线）和 **$\Phi 3.5\,\text{mm}$**（用于 1.5~2.5mm² 导线）的阻燃白色热缩管；
   - **成品梅花管方案**：如果买成品梅花号码管（0~9、A~Z），直接买一套组合盒装即可（约 ¥15 元），随剥随套，免加热快速固化。

> [!CAUTION]
> **【绝缘工艺硬红线】**：
> 1. 所有穿入接线端子的多股软线头，**严禁裸线直接拧入或搪锡拧入**（螺钉压紧后铜丝易散开、压断或发热松脱）；
> 2. 剥线长度严格控制在 **$8.0\sim 10.0\,\text{mm}$**，套入对应规格的 VE/TE 预绝缘管型端头后，使用**四边形/六角形棘轮冷压钳（HSC8 6-4A）**压实，压后外露绝缘护套必须紧贴金属端子开口，零铜丝外露！

### 4.1 核心工艺防踩坑细节
1. **线槽出线梳齿留弧度**：电线从 PVC 阻燃线槽梳齿缝穿出进入端子前，**必须保留 $3\sim 5\,\text{cm}$ 弧形微弯预留量**，严禁拉成紧绷直线（否则热胀冷缩易将接线框拉裂，且二次查线剥线无余量）；
2. **线号管排版一致性**：所有打印的热缩线号管，字迹必须清晰朝外。横向安装端子线号从左往右读，纵向安装端子线号从下往上读，全柜排版方向绝对统一；
3. **强弱电绝对分区入槽**：
   * 所有从漏保、微断引出的 220V 交流电线，**100% 只能进入【右竖线槽】与下层横槽**；
   * 所有来自 PLC 晶体管端口的 24V 信号线、传感器信号线，**100% 只能进入【左竖线槽】与中上层横槽**；
   * 严禁将 220V 电源线塞入左侧弱电线槽！

## 5. 出厂通电前静态检查与带电验证表 (Checklist)

配盘完成后，必须手持万用表完成以下打勾验收，合格后方可运往现场：

```markdown
- [ ] 1. 【断电断开摇测】断开所有设备电源，用 500V 摇表摇测 L-PE、N-PE，绝缘电阻必须 ≥ 20 MΩ。
- [ ] 2. 【接地连续性测试】万用表低阻档测量柜门、安装底板、上层托架到 PE 接地铜排的接触电阻，必须 ≤ 0.1 Ω。
- [ ] 3. 【220V 零火线核对】合上 QF0 漏保，万用表交流档测量 QF1~QF5 上桩头电压，必须稳定在 220V±10%，SPD 观察窗显示正常绿色。
- [ ] 4. 【直流 24V 极性核对】合上 QF1，明纬电源绿色 DC OK 灯亮起，万用表直流档测量明纬输出、10粒熔断端子及 TB1-P01~P12，确认电压在 24.0V~24.2V 之间，极性绝对无反接。
- [ ] 5. 【0V 汇流排连通测试】万用表蜂鸣档逐粒测量 TB1-N01 到 TB1-N12，中心短接排导通良好，全部响蜂鸣。
- [ ] 6. 【继电器线圈手动点亮测试】短接 PLC Y00 到 0V，KA01 继电器绿色动作指示灯必须清脆吸合点亮；万用表测量 TB2-01 与 TB2-02 瞬间导通闭合；断开后瞬间恢复开路。
- [ ] 7. 【第一期安全状态确认】核查导轨 3 右侧 TB2 端子排下桩头没有任何外线接入，确认处于 100% 无源悬空就绪状态。
```
