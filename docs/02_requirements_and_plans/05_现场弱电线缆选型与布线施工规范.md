## 4. DC 24V 分布式就地供电与远距离压降优化架构 (Distributed DC Architecture)

为彻底解决低压直流长距离输送（60~120米跨度）导致的严重压降、电动阀门欠压卡死与单点短路全厂瘫痪风险，系统采用 **“中枢稳压 + 二级动力箱就地降压供电”** 的分布式拓扑：

1. **AP-CTRL 中控柜主电源**：配置 **明纬 NDR-120-24 (24V DC / 5A)**，由 1kVA 在线式 UPS 受电，**专供 PLC 主机/扩展模块、研华工控机及就近的鱼池/调理池核心水质探头 (DO/氨氮/pH/EC)**。
2. **AP-WELL 深井就地动力箱**：导轨配置 **明纬 HDR-30-24 (24V DC / 1.5A)**，就地取 220V 电源，专供 V-01、V-02、V-03 补水电动阀与深井浮球，单程供电距离缩短至 $<3\,\text{m}$。
3. **AP-HYDRO 水培就地动力箱 (B3区)**：导轨配置 **明纬 NDR-75-24 (24V DC / 3.2A)**，就地专供 V-05 B3喷淋阀与立体水培架增压阀门，彻底消除 120 米长距压降。
4. **AP-HVAC 环控就地动力箱 (B2区)**：导轨配置 **明纬 NDR-75-24 (24V DC / 3.2A)**，就地专供 V-04 B2棚顶高压喷淋阀与天窗控制回路。
5. **控制隔离红线**：中控室 PLC 驱动各远端阀门时，**统一通过柜内中间继电器的无源干触点 (NO) 进行物理光电隔离**，严禁各箱 24V 电源正极互串！

## 5. 1kVA 在线式 UPS 不间断电源与断电保命续航规划

为防止电网瞬时失电导致工控机异常断电损坏数据库，并保证在断电期间现场传感器与报警推送不中断，控制柜内配置 **1kVA / 800W 在线式工控 UPS**：

### 5.1 弱电受电负荷清单与蓄电池容量计算
1. **弱电核心中枢常态功耗**：
   * 汇川 PLC + 继电器组：$15\,\text{W}$；
   * 研华工控机 (Intel N6210)：$20\,\text{W}$；
   * 16口工业交换机：$10\,\text{W}$；
   * 海康 NVR + 4TB 硬盘：$15\,\text{W}$；
   * 全厂传感器 (DO/氨氮/温湿度/电表)：$20\,\text{W}$；
   * **总保障功率 $P_{\text{UPS}} = 80\,\text{W}$**。
2. **后备续航时长计算**：
   * 采用 $24\,\text{V} / 20\,\text{Ah}$ 密闭铅酸/磷酸铁锂电池组，储电量 $W_{\text{bat}} = 24\,\text{V} \times 20\,\text{Ah} \times 0.85 = 408\,\text{Wh}$；
   * **断电持续运行时间**：$T_{\text{backup}} = \frac{408\,\text{Wh}}{80\,\text{W}} \approx \mathbf{5.1\,\text{小时}}$。
3. **断电保命自愈逻辑 (UPS Life-Saving Logic)**：
   * 当市电中断时，UPS 零切换时间（$0\,\text{ms}$）无缝供电；
   * 工控机立即触发 `POWER_FAIL_ALARM`，通过 4G 模组向管理人员手机推送断电警报；
   * 持续记录断电前后 5.1 小时内的全部水质宽表数据与传感器时序流至本地 SQLite，通网后自动补报，实现**数据黑匣子 100% 零丢失**。

## 7. 超五类屏蔽网线复合接线线序标准

```
+-------------------------------------------------------------------------------+
|                    Cat5e STP 超五类屏蔽网线 8 芯分配标准                      |
+-------------------------------------------------------------------------------+
|  【线对 1：蓝 / 白蓝】     =========>  RS485-A (Data+) / RS485-B (Data-)      |
|  【线对 2：橙 / 白橙】 \                                                      |
|  【线对 3：绿 / 白绿】  } ========>  并联接入 DC 12V/24V 电源正极 (V+)        |
|  【线对 4：棕 / 白棕】     =========>  并联接入 DC 12V/24V 电源负极 / 信号地 (GND)|
|  【铝箔屏蔽层 + 裸铜地线】 =========>  控制柜侧单端接入保护地 (PE)              |
+-------------------------------------------------------------------------------+
```

### 7.1 线序与功能定义详解
* **对 1 (纯蓝/白蓝)**：**RS485-A 与 RS485-B**。铁律：A 与 B 必须在**同一缠绕线对**内，利用原生双绞差分特性抵消外部电磁噪声。
* **对 2 + 对 3 (白橙/纯橙 + 白绿/纯绿)**：**DC 集中供电正极 (V+)**。4 根 AWG24 并联后，等效截面积提升至 **$0.8\,\text{mm}^2$**，将 $90\,\text{m}$ 走线的回路压降降低 $75\%$。
* **对 4 (白棕/纯棕)**：**DC 供电负极 (GND / 0V)**。2 根并联等效截面达 **$0.4\,\text{mm}^2$**。
* **屏蔽地线**：**仅在控制柜端接入 PE 地排，现场传感器端悬空包死，严禁双端接地引发地环流！**

## 8. M12 工业航空快插体系与【池位即端口】即插即测架构 (Tank-as-Port System)

为解决全厂 4,500 ㎡ 传感器频繁增删改、移动位置的痛点，弱电系统统一推行 **【方案二：池位即端口（插座固定池号，探头即插即测）】** 工业标准：

```
+-------------------------------------------------------------------------------+
|                 M12 A-Code 4针公头/母头标准引脚分配定义 (Pinout)              |
+-------------------------------------------------------------------------------+
|     【引脚 1 (Pin 1)】 ──── 棕色线 (Brown)  ───► DC +24V 电源正极             |
|     【引脚 2 (Pin 2)】 ──── 白色线 (White)  ───► RS485-A (Data +)             |
|     【引脚 3 (Pin 3)】 ──── 蓝色线 (Blue)   ───► DC 0V / GND 电源负极         |
|     【引脚 4 (Pin 4)】 ──── 黑色线 (Black)  ───► RS485-B (Data -)             |
|     【金属外壳】       ──── 屏蔽网 (Shield) ───► 压接金属防拉外壳 (360°屏蔽)  |
+-------------------------------------------------------------------------------+
```

### 8.1 “池位即端口”三大工程执行规则
1. **立柱固定 M12 防水接线盒（池位物理绑定）**：
   * 每个鱼池与水培区立柱高 $1.5\,\text{m}$ 处安装 IP68 金属航插分线盒，插座标识明确固化（如 `PORT-T01` 对应 1号鱼池、`PORT-T05` 对应 5号鱼池）；
   * 高空桥架至立柱分线盒的走线是一次性固化的，**后续永远不需要攀爬高空重放线缆**。
2. **探头通用化与免软件操作（即插即测）**：
   * 所有溶氧（DO）、氨氮、pH、水温探头统一装配 M12 A-Code 4 针金属公头；
   * 探头拔出插进任意池位插座，PLC 自动采集当前池位数据。农艺师与饲养员**无需修改 PLC 梯形图、无需重新下载程序、无需在网页端做任何配置**，30 秒手拧即拔即插！
3. **断线与空置保护机制**：
   * 当某个池位的探头拔出时，PLC 识别为 `PORT_EMPTY (空置)`，自动抑制该池误报警；
   * 重新插入后，系统在 $100\,\text{ms}$ 内完成通讯握手，自动恢复实时监测与保命联锁。

### 8.2 485 菊花链与隔离集线器拓扑
> [!CAUTION]
> **【总线拓扑铁律】**：每个区域的 M12 分线盒之间采用手拉手菊花链拓扑或工业级 RS-485 隔离中继器。在总线最末端节点的 A/B 端子之间，必须并接 **$120\,\Omega$ (1/4W) 终端匹配电阻**，吸收高频反射波。

## 9. 强弱电双层桥架物理隔离与两级线号管工艺

1. **双层桥架垂直间距**：严格遵循“强电在上（封闭金属槽）、弱电在下（镀锌网格式走线架）”规范，两层桥架垂直净距必须保持在 **$300\text{mm} \sim 350\text{mm}$**。
2. **两级线号管打标体系**：
   * **第一级：线缆外皮总标签 (Cable ID)**：采用包裹型自覆膜防水标签纸（如 `VEG-BUS-01`, `FISH-DO-01`）；
   * **第二级：端子芯线线号管 (Wire ID)**：采用 C 型免工具拆装卡扣线号夹（如 `485-A`, `485-B`, `+24V`, `0V`），压接绝缘针形冷压头 (VE0508)。

## 10. 🤝 弱电工程师必须与强电电工现场协同的 6 大交界接口规范

弱电施工人员在现场布线和调试时，必须主动与强电电工进行以下 6 大交界接口的双向核验与联调，严防“各干各的”导致信号烧毁或安全事故：

| 协同交界场景 | 弱电工程师操作与核验职责 | 强电电工配合操作职责 | 双方共同到场确认的验收红线 |
| :--- | :--- | :--- | :--- |
| **1. 双层桥架高空吊装** | 确认下层网格式弱电桥架标高与敷设路径 | 确认上层封闭式强电槽架卡扣紧固与接地跨接 | **实测两层垂直净距必须 $\ge 300\text{mm}$**，严禁弱电信号线掉入强电槽！ |
| **2. 电表与互感器二次侧接入** | 负责将 3 组互感器二次线接入电表 `I11~I32` | 负责卡装 3 只丁本 DBKCT24 到 160A 主出线上 | **共同确认 P1 面朝向电源侧**，电表二次线红进黑出，禁止带电拔插二次回路！ |
| **3. 接触器/软起动器信号联调** | 将 PLC 输出继电器与报警输入接入控制回路 | 确认交流接触器与软起动器控制端子接线正确 | **现场万用表量取无源干触点**，严禁强电 220V 误串入 PLC 24V 晶体管点位！ |
| **4. 联合防雷接地与屏蔽汇流** | 将弱电柜内 RVSP 屏蔽排引出一根 6mm² 黄绿线 | 负责将该黄绿线可靠压接至总等电位箱 (MEB) | **接地电阻实测严格 $\le 1.0\,\Omega$**，确认现场传感器端屏蔽层 100% 悬空绝缘。 |
| **5. 机旁【自动/停止/手动】旋钮** | 负责将 PLC DO 触点接入“自动”控制回路 | 负责将交流接触器线圈接入“手动”强启回路 | **联调三位带锁旋钮**，确认就地扳到“停止”时 PLC 无法强行远程合闸。 |
| **6. 气象站雨雪硬关天窗联调** | 将气象站常闭雨雪干触点串入天窗控制回路 | 负责天窗开窗电机主接触器受电合闸与限位调试 | **现场向气象站喷水**，验证 0.1 秒内天窗接触器强制释放断电、天窗安全闭合。 |
