## 🛠️ 数据规范与安全红线（【全局防护墙】）

> [!IMPORTANT]
> 凡是向系统贡献代码或进行二次设计的开发者，必须遵循以下核心约束：
> 1. **时钟必须对齐**：所有现场的 PLC、边缘网关与传感器时钟，必须通过 NTP 每小时强制同步，时差超过 $100\,\text{ms}$ 将触发系统熔断并拒收数据。
> 2. **网关宽表聚合**：全厂 100+ 监测点位必须由边缘网关按 5 秒 JSON 宽表打包上报，严禁单点高频写库，将 Cloudflare D1 数据库开支死锁在 0 元/月。
> 3. **人身与生物安全**：现场部署的 AMR 无人车必须配置超声波防撞与物理碰条；PLC 梯形图的“应急曝气与投喂熔断”硬件逻辑高于一切上层软件与云端 AI 指令。
