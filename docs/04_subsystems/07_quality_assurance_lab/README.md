# 鱼菜共生数字工业化工厂 · 品质控制与实验室子系统 (Quality Control & Lab Subsystem)

---

## 1. 系统定位与核心价值

在工业化鱼菜共生生态闭环中，**品质控制与驻厂实验室（QC Laboratory）** 是全厂产品实现 **300%+ 终端品牌溢价** 与 **大客户/高端会员免检信任** 的最高守门人（Gatekeeper）。

品质主管对出厂产品拥有**一票否决权（Release Gatekeeper）**。驻厂实验室对每一批采收的水培蔬菜与出塘循环水产执行严格的双维度指标检验：
1. **安全红线指标（Food Safety & Zero Contaminants）**：农药 0 检出、抗生素 0 检出、低硝酸盐（母婴级 $< 800\text{ mg/kg}$）、重金属极微、致病微生物阴性、水产无土腥味；
2. **超额营养与风味指标（Nutritional Value & Sensory Profile）**：维生素 C 富集（$+110\%$）、可溶性糖度（Brix $\ge 4.0$）、加州鲈粗蛋白（$\ge 19.8\%$）、微量元素微生态富集。

每批次检测合格后，系统自动生成不可篡改的 **e-COA（电子质量检验合格证书）**，并向 B2B 交付链与 C 端一物一码区块链防伪节点注入哈希存证。

## 3. 全生命周期三级质检与前置干预架构 (IQC ➔ IPQC ➔ OQC)

为彻底根除传统农业“只在采收后做检测、出现问题只能报废”的滞后弊端，系统构建全生命周期三道质检防线：

```mermaid

        I1[种苗/基质/特种膨化料入厂] --> I2{安全性与纯度快检}
        I2 -->|合格| S1[准入生产跑道/鱼池]
        I2 -->|异常| I3[🚫 拒收入库与退货]
    end

    subgraph 2. 生产过程动态质检与前置干预 IPQC (核心前道防线)
        S1 --> P1[苗期移栽 Gate 1: SPAD/胚轴粗壮度]
        P1 -->|弱苗/病苗| P1_act[前置淘汰, 杜绝病原入槽]
        P1 --> P2[旺长期 Gate 2: 汁液硝酸盐速测 + 矿质微量元素]
        P2 -->|NO3偏高| P2_act1[🚨 提前 7 天下发: 硝酸盐代谢促降冲洗 + 调优进水氮比]
        P2 -->|钙吸收滞后| P2_act2[🚨 提前 5 天下发: 增强垂直对流 + 钙素叶面微喷]

        P3 -->|糖度 < 4.0| P3_act1[⚡ 提前 48h 开启: 连续红蓝光增糖配方 + 8°C 昼夜大温差]

        P4 -->|检出土腥味 >10ng/kg| P4_act1[🌊 提前 7 天转入: 微气泡活水吊水净化槽 72h 停食排毒]
    end

    subgraph 3. 出厂放行终检 OQC 与 e-COA 签发
        P3 -->|冲刺达标| O1[采收/出塘成品终检]
        P4 -->|净化归零| O1
        O1 --> O2{双维度红线判定}
        O2 -->|特级达标| O3[🟢 签发防伪 e-COA 电子合格证]
        O3 --> O4[向 B2B 履约链与 C 端一物一码注入 SHA-256 存证]
    end
```

## 4. 生产过程动态质检 (IPQC) 关键节点与前置农艺干预 SOP

### 4.1 水培蔬菜过程动态质检 (Hydroponics IPQC Gates)
1. **Gate 1: 育苗移栽期质检（定植第 3 ~ 5 天）**
   - **抽检项目**：叶绿素 SPAD 初值（$\ge 35.0$）、胚轴粗壮度（径粗 $\ge 2.2\,\text{mm}$）、根系白度与活力、真菌/虫卵显微初筛；
   - **前置干预**：自动识别弱苗、徒长苗与根腐苗并机械剔除，杜绝病弱植株占据跑道孔位，确保整槽齐苗率 $\ge 98.5\%$。
2. **Gate 2: 旺盛生长期组织汁液与微量元素过程抽检（定植第 10 ~ 14 天）**
   - **硝酸盐速测 ($NO_3^-$)**：采用分光光度法与试纸反射法快速测定叶柄汁液。若实测值 $>1200\text{ mg/kg}$（预测出厂超标风险），**系统提前 5~7 天自动下发《硝酸盐促降指令》**——将跑道进水硝态氮降低 30%，采收前 48 小时切换至纯水微流循环，促使植株将硝酸盐充分转化为氨基酸与蛋白质，确保出厂稳定 $<800\text{ mg/kg}$。
   - **矿质微量元素抽测（TAS-990 原子吸收仪）**：抽测钙（Ca）、铁（Fe）、镁（Mg）。若钙吸收速率偏低（预警心叶顶烧病 Tipburn），**提前 5 天启动跑道上方环流风机强化气孔蒸腾**，并微喷 $0.2\%$ 糖醇钙。
3. **Gate 3: 采收冲刺期糖度风味预检与工位卫生（采收前 48 小时）**
   - **糖度 Brix 预检**：手持数字折光仪抽测组织汁液糖度。若 Brix $< 4.0^\circ\text{Brix}$，**提前 48 小时自动下发《光温增糖工单》**——开启植物补光灯连续红蓝光照射（延长光照 4h），并将夜间温室目标温度下调 $3.5^\circ\text{C}$，拉大昼夜温差至 $10^\circ\text{C}$，迫使光合碳水化合物转化为还原糖与可溶性固形物，确保最终糖度达到 $\ge 4.2^\circ\text{Brix}$。
   - **采收工位 ATP 生物洁净度**：采收机械臂夹爪、周转箱与浮板接触面采用 ATP 荧光拭子快检（$<30\text{ RLU}$），确保采收作业环境洁净度。

### 4.2 循环水产过程动态质检 (Aquaculture IPQC Gates)
1. **Gate 1: 苗种入池检疫（入池 Day 0）**
   - 病毒 PCR 试纸快速检测、体表寄生虫镜检与水质盐度适应性试验，杜绝带病苗种入池。
2. **Gate 2: 育成期水体与生理代谢抽检（每 15 天）**
   - 鱼体肥满度、肝胰脏指数（HSI）、水体亚硝酸盐（$NO_2^- < 0.1\text{ mg/L}$）与氨氮积累速率监控。
3. **Gate 3: 起捕前 7~10 天土腥味净化期过程质检（关键质量防线）**
   - **几何土味素 (Geosmin) / 2-MIB 气相与分光速测**：在成鱼计划起捕前 7 天，抽取肌肉样品分析土腥味浓度。
   - **前置活水吊水干预**：若检出土腥味 $>10\text{ ng/kg}$，**系统立即在起捕前 7 天生成工单，将该池加州鲈转入“微气泡富氧活水吊水净化槽（Depuration Tanks）”**，执行 72~120 小时停食吊水、大流量纯水冲淋与微纳米气泡暴气，促使鱼体脂肪代谢掉土味素，直到复检 Geosmin 为 $0\text{ ng/kg}$ 方可安排起捕装车，**绝不等成鱼出塘交接给客户时才发现土腥味！**

### 5.2 安全与营养三级判定红线流程

1. **安全红线判定（一票否决权）**：
   - 任何农残、违禁抗生素、重金属超标或硝酸盐 $>1500\text{ mg/kg}$，系统自动锁死放行权限，强制阻断物流装车并触发根因排查。
2. **超额营养风味判定（溢价分级）**：
   - **特级母婴/高端直配级（满分放行）**：硝酸盐 $<800\text{ mg/kg}$ 且 糖度 $\ge 4.0^\circ\text{Bx}$ 且 维C $\ge 25\text{ mg/100g}$，签发特级 e-COA 电子合格证；
   - **一级商超大宗级**：硝酸盐 $800 \sim 1500\text{ mg/kg}$，糖度 $3.5 \sim 4.0^\circ\text{Bx}$，允许商超大宗配送，同时向生产端下发光温调优工单。

## 6. 电子防伪质量证明书 (e-COA) 与溯源存证

每次批次放行，系统根据实验室原始检验数据自动生成标准 JSON 数据包，并使用工厂私钥进行 SHA-256 数字签名：
1. **B2B 商超核验**：商超收货仓扫码即可调取原始光谱图、色谱图与出厂检测报告；
2. **C 端消费者扫码**：C 端小程序直观展示“农残0检出证明”、“母婴级低硝酸盐证书”与“维C富集勋章”；
3. **不可篡改防伪链**：所有 e-COA 数据哈希自动广播至分布式节点，杜绝任何人工后门篡改。

## 7. 留样观察室与 CAPA 闭环整改机制

1. **4°C 实验室专业留样恒温冷藏箱 (硬件规范与 SOP)**：
   - **选用设备**：**海尔生物医疗 HYC-310A（310升 · 电加热 LOW-E 防雾玻璃门 · 2~8°C 医用恒温箱）**，占地仅 $0.37\,\text{m}^2$（外部尺寸 $600\times 630\times 1840\,\text{mm}$），带医疗器械注册证与双安全门锁。
   - **微气调温控与防雾**：出厂设定恒温 $4.0^\circ\text{C} \pm 0.5^\circ\text{C}$，风冷无霜循环微风不冻伤菜叶，电加热玻璃门彻底杜绝温室/梅雨季门体凝露结雾。
   - **留样容量与批次管理**：配备 5 层独立高承重搁架与批次条码卡槽，常态化容纳 **40 ~ 50 盒**出厂留样（每批次留样净菜 2 盒、冷鲜鱼 1 盒）。
   - **留样周期与法律举证**：恒温保存 **72 ~ 120 小时（3 ~ 5 天）**，完全覆盖产品货架流通与消费周期；配备 **USB 数据存储模块**，分钟级记录历史温度报表，用于商超验厂与客诉复检仲裁举证。
   - **货架期跟踪**：每日监测 5 天平均失重率（$< 2.0\%$，实测 $1.85\%$）与维 C 保持率（$> 85\%$，实测 $88.5\%$）。
2. **质量 CAPA（纠正与预防措施）联动**：
   - 当检测出现轻微偏离（如糖度降至 3.4°Brix），系统自动向种植长下发《光环境调优工单》——将采收前 48 小时的光照强度提高 15%，促进光合产物糖分累积；
   - 当水体悬浮物微升，自动向养殖长下发《微滤机反冲洗频率调增工单》，形成生产、检测、纠偏全自动闭环。
