## 1. Cloudflare D1 数据库表结构 (SQLite DDL)

> **时间字段硬性规范**：所有时间字段统一存储为 **严格 ISO 8601 UTC 字符串**（格式：`YYYY-MM-DDTHH:mm:ss.sssZ`，例如 `2026-11-16T08:09:00.000Z`），禁止使用本地时区或纯日期简写。

### 1.1 建表 DDL (`migrations/0001_video_init.sql`)

```sql
-- 1. 摄像头机位主表（权限分级与运行模式配置中心）
CREATE TABLE IF NOT EXISTS cameras (
  cam_id TEXT PRIMARY KEY,                         -- 如 CAM-FISH-PAN-01
  site_id TEXT NOT NULL,                           -- 基地编号，如 guangming-01
  name TEXT NOT NULL,                              -- 中文名称，如 鱼池全景（向北）
  zone TEXT NOT NULL CHECK (zone IN ('gate', 'fish', 'hydro', 'equip', 'lab', 'pack')),
  visibility TEXT NOT NULL CHECK (visibility IN ('internal_ops', 'public_trace')),
  ip_address TEXT NOT NULL,                        -- 局域网固定 IP，如 192.168.1.104
  rtsp_channel INTEGER NOT NULL DEFAULT 102,       -- 海康子码流通道号 102 (主码流101仅供NVR)
  stream_mode TEXT NOT NULL DEFAULT 'snapshot'
    CHECK (stream_mode IN ('snapshot', 'on-demand', 'continuous-hls', 'disabled')),
  audio_enabled INTEGER NOT NULL DEFAULT 0,        -- 0=强制剥离音轨(-an)，1=允许音轨(仅限internal_ops)
  online_status TEXT NOT NULL DEFAULT 'unknown'
    CHECK (online_status IN ('online', 'offline', 'degraded', 'unknown')),
  last_seen_at TEXT,                               -- 最近一次RTSP拉流成功时间 (ISO 8601 UTC)
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_cameras_site_vis ON cameras (site_id, visibility);

-- 2. 定时延时快照索引表
CREATE TABLE IF NOT EXISTS snapshots (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id TEXT NOT NULL,
  cam_id TEXT NOT NULL,
  r2_key TEXT NOT NULL UNIQUE,                     -- snapshots/{site_id}/{cam_id}/{YYYY}/{MM}/{DD}/{iso_utc}.jpg
  captured_at TEXT NOT NULL,                       -- 抓拍时间 (ISO 8601 UTC)
  size_bytes INTEGER NOT NULL,
  width INTEGER NOT NULL DEFAULT 1280,
  height INTEGER NOT NULL DEFAULT 720,
  created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_snapshots_query ON snapshots (site_id, cam_id, captured_at DESC);

-- 3. HLS 视频分片索引表
CREATE TABLE IF NOT EXISTS hls_segments (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  site_id TEXT NOT NULL,
  cam_id TEXT NOT NULL,
  r2_key TEXT NOT NULL UNIQUE,                     -- hls/{site_id}/{cam_id}/{YYYY}/{MM}/{DD}/{iso_utc}.ts
  start_at TEXT NOT NULL,                          -- 分片起始时间 (ISO 8601 UTC)
  duration_sec REAL NOT NULL,                      -- 分片时长(秒)，默认约 30.0
  size_bytes INTEGER NOT NULL,
  created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_hls_query ON hls_segments (site_id, cam_id, start_at DESC);

-- 4. 报警/事件短视频留档表
CREATE TABLE IF NOT EXISTS video_events (
  event_id TEXT PRIMARY KEY,                       -- 如 ALM-20261116-001
  site_id TEXT NOT NULL,
  cam_id TEXT NOT NULL,
  source_type TEXT NOT NULL,                       -- 如 do_low | ammonia_high | manual_clip
  trigger_at TEXT NOT NULL,                        -- 触发时刻 (ISO 8601 UTC)
  start_at TEXT NOT NULL,
  end_at TEXT NOT NULL,
  r2_key TEXT,                                     -- events/{site_id}/{cam_id}/{event_id}.mp4
  status TEXT NOT NULL DEFAULT 'pending'
    CHECK (status IN ('pending', 'uploading', 'ready', 'failed')),
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_events_query ON video_events (site_id, cam_id, trigger_at DESC);

-- 5. 边缘控制指令队列（解决 4G 无公网 IP 的按需唤醒与配置下发）
CREATE TABLE IF NOT EXISTS agent_commands (
  cmd_id TEXT PRIMARY KEY,
  site_id TEXT NOT NULL,
  cam_id TEXT NOT NULL,
  action TEXT NOT NULL
    CHECK (action IN ('wake_live', 'sleep_live', 'capture_now', 'clip_event', 'reload_config')),
  payload_json TEXT NOT NULL DEFAULT '{}',         -- 如 {"ttl_sec":180,"protocol":"hls"}
  status TEXT NOT NULL DEFAULT 'pending'
    CHECK (status IN ('pending', 'acked', 'completed', 'expired', 'failed')),
  expires_at TEXT NOT NULL,                        -- 指令超时时间 (ISO 8601 UTC)
  created_at TEXT NOT NULL,
  acked_at TEXT
);

CREATE INDEX IF NOT EXISTS idx_commands_poll ON agent_commands (site_id, status, expires_at);
```

## 2. 边云通信与 4G NAT 穿透信令协议

由于倍控 N100 位于 `TP-LINK TL-TR904` 4G 路由器之后，**没有固定公网 IP**，云端网关无法主动发起连接。所有控制与状态同步均采用 **“边缘主动上报心跳 + 响应体捎带下发指令”** 模式，最大限度节省 4G 流量与握手开销。

### 2.1 边缘端接口鉴权
边缘端（`video-agent`）调用 `/api/internal/agent/*` 时必须携带：
* `X-Site-Id`: `guangming-01`
* `X-Timestamp`: 严格 ISO 8601 UTC（网关校验时间漂移 $\le \pm 60\,\text{s}$）
* `X-Signature`: `HMAC-SHA256(AGENT_SECRET, "{method}\n{path}\n{timestamp}\n{sha256(body)}")`

### 2.2 合并心跳与指令拉取 (`POST /api/internal/agent/heartbeat`)
* **轮询频率**：默认每 **`10 秒`** 一次；当存在活跃 `wake_live` 会话时切换为 **`3 秒`** 一次（以便及时续期或接收新指令）。
* **边缘端请求体**：
  ```json
  {
    "agent_version": "1.0.0",
    "sent_at": "2026-11-16T08:09:00.000Z",
    "ram_disk": {
      "mount": "/mnt/hls_ram",
      "used_mb": 42,
      "limit_mb": 512
    },
    "cameras": [
      { "cam_id": "CAM-FISH-PAN-01", "status": "online", "active_live": false }
    ]
  }
  ```
* **云端响应体（捎带 `pending` 且未过期的指令 + 期望模式）**：
  ```json
  {
    "server_time": "2026-11-16T08:09:00.120Z",
    "commands": [
      {
        "cmd_id": "CMD-20261116-991",
        "cam_id": "CAM-FISH-P5-01",
        "action": "wake_live",
        "payload": { "ttl_sec": 180, "segment_sec": 4 },
        "expires_at": "2026-11-16T08:10:00.000Z"
      }
    ],
    "desired_modes": {
      "CAM-FISH-PAN-01": "snapshot",
      "CAM-FISH-P5-01": "on-demand"
    }
  }
  ```

### 2.3 指令回执 (`POST /api/internal/agent/commands/{cmd_id}/ack`)
边缘端收到 `wake_live` 后立即启动对应一路的 `FFmpeg` 低延迟切片（建议按需直播时采用 **`4 秒` 小分片**以把首帧等待压到 `5~8 秒`），并在首片上传成功后上报：
```json
{
  "status": "completed",
  "finished_at": "2026-11-16T08:09:05.400Z",
  "detail": "hls live stream started"
}
```

### 2.4 文件直传 R2 与索引注册
1. 边缘端通过 `POST /api/internal/agent/upload-url` 批量申请 R2 预签名 PUT URL（或使用受限范围的 R2 S3 API Token 直传 `snapshots/`、`hls/`、`events/`），**避免二进制视频流穿透 Worker 消耗 CPU 时间**；
2. R2 PUT 成功后，调用 `POST /api/internal/agent/ingest` 批量写入 D1（`snapshots` / `hls_segments` / `video_events`）；
3. 边缘端收到 `200 OK` 后，立即删除 `/mnt/hls_ram` 对应本地分片。

## 3. 对外播放鉴权、防盗链与动态 M3U8 规范

### 3.1 短时效播放 Token
* 外部系统调用 `GET /api/v1/streams/{cam_id}/live` 或 `/playback` 时，网关先核验调用方 JWT 权限：
  * 若调用方为 C 端公开溯源服务（`role = public_viewer`），**强制校验 `cameras.visibility = 'public_trace'`**，访问 `internal_ops` 机位一律返回 `403 Forbidden`。
* 校验通过后签发有效期 `600 秒` 的 HMAC-SHA256 播放 Token，绑定 `cam_id`、`scope` 和 `exp`。

### 3.2 动态 `.m3u8` 播放列表生成
`Video Gateway` 不直接把 R2 静态 `.m3u8` 暴露给前端，而是由 `/sign/{token}/hls/{cam_id}/live.m3u8` 或 `/playback.m3u8` 实时查询 D1 `hls_segments` 表动态拼接：
* 每个 `.ts` 分片 URL 均带独立签名（或通过 Worker 带缓存代理转发 R2 对象）；
* **自动续期保活机制**：当播放器持续请求 `live.m3u8` 时，网关刷新该机位的“最后观看时间”；若连续 **`180 秒`** 无人请求，在 `on-demand` 模式下网关自动写入一条 `sleep_live` 指令给边缘端停流省流量。
