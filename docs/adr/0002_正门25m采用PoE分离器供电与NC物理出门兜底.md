# ADR-0002：正门 25m 采用 PoE 分离器供电与 NC 物理出门兜底

## 背景
中央控制柜 `AP-CTRL` 距离正门约 25 米，需要部署 280KG 电磁锁、远程开门继电器，并希望利用正门摄像头的人脸识别能力。

## 决策
1. **48V PoE 远传 + 就近降压**：从主柜 `GPS424 V3` 拉一根 `Cat5e STP` 网线送 48V IEEE 802.3at PoE 到正门，通过 PoE 分离器就近转 `12V / 2A` 供磁力锁与网口继电器，同时享受主柜 UPS 备电。
2. **硬线物理兜底**：门内侧物理串联常闭（NC）出门按钮，断网或工控机宕机时可一键物理断电开锁。
3. **2D 人脸定位限制**：现有枪机为 2D 可见光识别，仅用于“远程一键开门辅助 + 到访提醒”，不直接作为无人值守防盗自动开锁依据。

## 被放弃的备选方案
* 从主柜直接拉 25m 12V 直流线（来回 50m 线损压降大，磁力锁吸合时易掉电重启）。
* 仅用 2D 监控人脸直接全自动开门（存在照片/视频欺骗安全风险）。
