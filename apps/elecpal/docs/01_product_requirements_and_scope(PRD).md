## 🎯 一、 产品愿景与目标定位

传统工业电气工程中，AutoCAD Electrical 与 EPLAN P8 属于笨重的专业桌面单机软件，学习成本极高、无法云端协作、选型计算与图纸脱节、图纸变更易出错。

**ElecPal (电气伴侣)** 的核心愿景是：
> **“以工业级数据契约（JSON）为单一真实源，融合 GB/IEC 国家规范与 AI 智能推演，让电气工程师在浏览器中 1 秒完成选型校验、生成专业工程图纸并导出 AutoCAD DXF/BOM。”**

## 📋 三、 核心功能模块与已裁决技术规范

### 1. 🔐 身份认证与双模混合存储 (已定稿: 方案B 双模混合)
* **未登录 (游客模式)**：使用浏览器 LocalStorage / IndexedDB 进行本地离线临时设计，支持下载与导入 `.json` 单文件；
* **登录后 (Firebase Google Auth)**：一键免密 Google 登录，自动将本地草稿无缝同步至 Firebase Firestore 云端项目库，享受多设备漫游与历史快照；
* **多工程/多车间项目管理 (Projects CRUD)**：创建工程（如：01号鱼菜车间、02号育苗车间、成都基地）、重命名、归档；
* **拓扑版本快照时间线 (Version Snapshots)**：记录每次提交记录（如 `V1.0 初始设计` ➔ `V1.1 升级正泰160A总闸`），支持历史快照对比与一键回退。

### 2. 🧮 核心计算与 ERC 规则引擎 (已定稿: 严格阻断式 Strict Blocking)
* **负荷计算 (Load Calculation)**：自动汇总设备额定功率 $P_e$，计算计算功率 $P_{js}$、计算电流 $I_{js}$ 与无功补偿建议；
* **断路器级差防越级跳闸断言**：一级总闸 $I_{n1} \ge 1.6 \times I_{n2}$，短路分断能力 $I_{cu} \ge I_k$；
* **电机回路防启动误跳断言**：三相电动机回路强制采用 D 型动力微断（瞬时脱扣 $10\sim 14 I_n$）；
* **电缆截面载流量与压降断言**：电缆允许载流量 $I_z \ge I_n$，末端压降严格 $\Delta U\% \le 5.0\%$；
* **🚨 严格阻断机制 (Strict Blocking)**：凡存在越级跳闸、电机错配 C 型微断、电缆载流量过载等 ERC 物理安全红线时，**系统强制阻断正式 AutoCAD DXF 施工图纸导出**，必须消除隐患后方可放行！

### 3. 📐 工业级正交 Web CAD 矢量画布
* **三大标准工程图卷无缝切换 (GB/T 18135)**：
  * **【图卷 1: ELEC-01】**：全厂低压动力配电一次系统图 (强电 380V/220V)；
  * **【图卷 2: ELEC-02】**：PLC 自动化控制与 I/O 接线原理图 (弱电自控 24V)；
  * **【图卷 3: ELEC-03】**：RS-485 现场总线与工控物联网络拓扑图 (通信与网络)；
* **专业 CAD 视口交互**：滚轮 20%~300% 无损矢量缩放、鼠标平移拖拽、适屏居中 (Fit)；
* **双模式切换**：经典 CAD 暗黑深蓝工程底 ⇄ 设计院标准白图底；
* **标准工程图框与标题栏 (GB/T 10609.1)**：动态联动图名、图号、版本、设计与审核栏。

### 4. 🤖 AI Copilot 智能推演辅助 (已定稿: 全景三模态交互)
* **Prompt-to-SLD (自然语言一键推演全图)**：输入工厂/车间文字描述，AI 自动推演负荷并生成合法 JSON 拓扑；
* **Chat Copilot (侧边栏多轮局部微调)**：支持对话式局部调整（如：“将3号泵升为4kW，电缆自动升级”），实现精准局部 Patch；
* **Photo-to-JSON (多模态实物逆向)**：上传现场配电箱/断路器铭牌照片，VLM 视觉大模型提取参数并自动逆向建档；
* **AI 安全质检员**：一键诊断越级跳闸与选型缺陷。

### 5. 💾 AutoCAD DXF 工业级导出 (已定稿: AutoCAD R12/2000 ASCII 标准)
* **标准 DXF 格式导出**：严格采用通用 AutoCAD R12 / R2000 ASCII 规范，分层输出 `0-BUSBAR`（母排）、`0-POWER`（动力线）、`0-SYMBOLS`（符号）、`0-TEXT`（标注），保证在任意版本 AutoCAD、浩辰与中望 CAD 中 100% 打开不乱码；
* **成套厂采购 BOM 与端子线号表 (.csv / .xlsx)**；
* **高分辨率矢量 SVG / 蓝图 PDF 打印**。
