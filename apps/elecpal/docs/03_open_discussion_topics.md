## 📋 决议细则与落地指南

### 1. DISC-01 (云端存储)：双模混合策略
- **未登录工程师**：自动启用 LocalStorage 离线单机沙盒，可导入导出单文件 `.json`；
- **Google 登录后**：自动将本地草稿静默同步至 Firebase Firestore 云端项目库，享受多端云漫游与拓扑版本快照。

### 2. DISC-02 (AI 交互)：全景三模态交互
- 支持 **自然语言一键推演生成整图**；
- 侧边栏支持 **多轮自然语言精准局部 Patch（如：将3号泵由3kW改4kW并自动换电缆）**；
- 支持 **实物铭牌照片（如正泰 NXM-250S）直接拖拽 OCR 逆向建模**。

### 3. DISC-03 (AutoCAD 导出)：标准 R12/2000 ASCII DXF 规范
- 统一输出多图层标准 DXF（`0-BUSBAR`、`0-POWER`、`0-SYMBOLS`、`0-TEXT`），保证在任意版本 AutoCAD、浩辰、中望 CAD 中无缝打开编辑且中文文字不乱码。

### 4. DISC-04 (ERC 规则)：严格阻断式 (Strict Blocking)
- 若存在越级跳闸（上级开关额定电流不足）、电机错配 C 型微断、电缆载流量过载等物理安全红线时，**系统强制禁用并阻断正式 AutoCAD DXF 施工图导出**，必须消除所有 ERROR 级别隐患后方可放行！
